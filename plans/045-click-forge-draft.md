## 2. 원칙 충돌 검사

| 요구 | 부딪히는 원칙 | 판정 · 대안 |
|---|---|---|
| ⓐ 망치(도구) 업그레이드 트랙을 새로 | 4 결정 소수 정예 · 재화 셋 구조 | **새 재화·새 트랙은 기각.** 대안: **망치 단계 = 제련 강화 레벨의 표시**(제련 0·7·14·21·28 에서 망치 모양이 바뀜). 이미 「제련 강화 → 등급 분포 상승」이 「도구가 좋아질수록 뽑기가 좋아진다」와 같은 것이다. 결정 0개 증가, CORE 0줄 |
| ⓐ 3개 합성 | 8 인벤토리 금지 · 5 RNG 층 | **기각.** 같은 것 3개를 모으려면 보관이 필요하다. 「9등급×2 → 10등급」 합성은 이미 「미확정」에 있다 |
| ⓑ 업적 | 3 콘텐츠는 공식 · 7 첫 3분 | **조건부 가능.** 업적을 손으로 나열하지 않고 **공식으로 생성**: 최고 웨이브 10·25·50·100·150…(×1.5 계열) / 등급 n 첫 획득(15개) / 승천 1·2·3…회 / 제련 레벨 5단계마다. 첫 3분엔 목록을 숨기고 달성 알림만 |
| ⓑ 보상 = 추가 뽑기 | 6 보상은 정액형만 · 「병목 아닌 자원은 아무도 원하지 않는다」 | **정액이면 가능.** 단 026 실측(하루 스핀 51배에도 w200 16→14일) 대로 **뽑기 횟수는 병목이 아니라 보상감이 약하다.** 대안: 보상을 **「임계압 정렬 1회」**(천장 강제 정렬을 바로 쓰는 권리)로 준다 — 고정 토큰과 합치면 원하는 부위 전릴 정렬이 되어 결정 ④(조준)에 힘이 실린다. 새 RNG 층 0 |
| ⓒ 망치질로 별도 뽑기 | 검증 기준 「접속 시간(10~120분)과 도달 일수가 무관」 · 026 「스핀 무한」 결함 | **무제한이면 기각**(누른 만큼 진행 = 접속 시간이 곧 진행). 대안: **열기(熱) 게이지** — 모루를 누르면 열기가 오르고 N번에 뽑기 1회. **박자를 맞추면(Starsmith 의 FORGE RUSH 방향) 한 번에 열기가 더 오른다** — 연타 속도가 아니라 박자에 보상하므로 오토클리커가 이득이 없고 손맛이 남는다. 열기는 **시간으로만 채워지는 상한**이 있다(예: 상한 = 뽑기 30회분, 오프라인 델타로 회복). 상한이 있으니 하루 총량이 접속 시간과 무관해진다. 이것은 038 의 **043 타격 연출(릴 → 모루)** 과 같은 자리다 — 043 에 흡수하는 것을 추천 |

## 3. 사용자 결정 — 정해져야 지시서로 쪼갠다

**결정 ① 망치 업그레이드** — (가) 제련 레벨의 **모양만** 바꾼다(추천, 결정 0개 증가) / (나) 별도 업그레이드 트랙(원칙 4 위반 — 근거 필요)

**결정 ② 업적 보상** — (가) **임계압 정렬 1회 + 소량 충전**(추천) / (나) 충전(뽑기) N회만 / (다) 고정 토큰

**결정 ③ 망치질 뽑기** — (가) **열기 상한형, 043 에 흡수**(추천) / (나) 상한 없음(페이싱 기준 위반 — 반려 대상)

**결정 ④ 순서** — 1.0 완주선(041 → 040 → 042 → 043 → 044 → 재제출) 안에 넣을지.
추천: **ⓒ 는 043, 업적은 042(첫 30초 온보딩 = 「분명한 목표」 038 ✘ 항목)에 얹는다.** 따로 줄을 세우면 재제출이 늦어진다.

## 4. 결정 뒤 가안 (수치는 전부 `days.js` 로 재서 확정 — 지금 숫자는 자리표시)

- **열기**: 모루 탭 1회 = 열기 +1(박자 콤보 중 +2~3) · 열기 10 = 뽑기 1회(충전 소모 없음) · 열기 저장 상한 300(= 30회) · 회복 6초/1.
  완료 조건: `days.js` 에 「열기 전부 소진」 플레이를 추가해 **10분·120분 접속에서 w75·첫 승천 도달 일수 차가 노이즈 바닥 이내.**
- **업적**: 저장은 `S.ach` 비트 하나(localStorage, 서버 없음). 보상 수령은 버튼 1회 · 같은 업적 재수령 0.
  「보상 버튼은 몇 번까지, 무엇을 대가로」 검사를 둔다(026 교훈).
- **망치 단계**: 손그림 상한 안에서 망치 실루엣 3장 이하 + 팔레트 스왑. 상한(현재 38)을 올리면 그 수를 문서에 적는다.
