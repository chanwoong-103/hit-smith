### ⑤ 「세 번 두드리면 하나」 — VIEW 의 상태 기계 하나

CORE 의 `spin()` 은 **한 번만** 부른다(첫 타). 결과는 그 순간 정해지고 420ms 뒤 화면에 쓰인다. VIEW 는 그 결과를 **타격 수만큼만 보여 준다**.

```
VIEW.forge = { need:0, struck:0, shown:0, veiled:false, settled:false, qHeld:0, lastHitAt:0,
               strikes:{hand:0, apprentice:0, idle:0}, made:0, blocked:{charge:0, queue:0}, idleFinish:0 }
```

1. **치기 `strike(src)`** (`src` = `'hand'`|`'apprentice'`|`'idle'`):
   - 주기 밖(`!veiled`): 033 ② 의 「가득 + 정리 꺼짐」이면 지금처럼 `openCmp()`. 아니면 `spin()` 을 부르고 **`spinning` 이 참이 됐는지로** 시작 여부를 안다.
     시작했으면 `veiled=true · need=REELS() · struck=1 · settled=false` 와 부르기 직전의 `S.queue.length` 를 기억한다.
     시작 못 했으면 **왜 못 했는지**(충전 0 / 대기열 가득)를 `blocked` 에 세고, 열기 막대 또는 대기열 띠를 한 번 깜빡인다(새 팝업·새 글자 없음).
   - 주기 안: `struck++`. `struck ≥ need` 면 ⑦ 마무리.
   - 매 타: 기존 불티 터짐 1회 + 짧은 셰이크(지금 있는 `__fxBurst`·셰이크 함수 재사용 — 새 연출 금지). `lastHitAt` 갱신.
2. **정착 감지**: `spinning` 이 참 → 거짓으로 바뀐 것을 rAF 로 본다. 그때 `settled=true`, `qHeld = S.queue.length − 기억한 길이`(자동 판매면 0).
   **정착 전에 온 타격은 쌓아 두었다가 정착하는 순간 한꺼번에 반영한다**(빨리 세 번 친 사람도 결과가 맞게).
3. **가림막은 부모에 건다**: `#forge` 에 `data-shown="k"` · `data-veiled` 를 달고 CSS 로 `k` 번째 뒤의 `.reel` 을 덮고(빈 화로 칸 + 「?」 — 목업), `#msg` 를 감춘다.
   ⚠ **자식 클래스로 걸면 안 된다** — CORE 가 `#msg.className=` 로 통째로 덮고 `.reel` 클래스를 붙였다 뗀다(§1 ②④). 부모 속성은 CORE 가 안 만진다.
4. **보이는 문양 수** `shown = settled ? min(struck, need) : 0`. 두 번째 문양부터는 앞 문양과 같으면 그 칸을 강조한다(목업의 이은 고리 — CSS 만).
5. **불티 이음매(≈3866행)는 «정착»이 아니라 «드러남»에 묶는다.** 지금은 CORE 가 `.reel.hit` 를 다는 순간(=정착) 터지므로 첫 타에서 결과가 새어 나간다.
   `hit` 연출은 그 칸이 **드러날 때** 낸다. (검사 K5.)
6. **가려진 동안의 대기열·정리**: 대기열 띠와 `#qn` 은 `S.queue.length − qHeld` 를 보인다. **`autoResolve()` 는 가려진 동안 돌지 않는다**(아직 안 나온 장비를 정리하면 안 된다).
   골드(자동 판매)는 정착 순간 오른다 — 알고 둔다(CORE 가 그 순간 더한다). 「구현 결과」에 적기만.
7. **마무리**: 남은 문양을 다 열고, `#msg` 를 보이고, `qHeld=0`, `made++`, `veiled=false`. 장비가 나왔다는 표시는 R1 에선 **대기열 띠의 새 점이 한 번 반짝** 정도(CSS) — 날아가는 카드는 R2.
8. **손 놓으면 마저 친다**: 주기 안에서 마지막 타격 뒤 **1.5초** 동안 아무도 안 치면, 남은 타격을 `'idle'` 로 0.25초 간격으로 친다(`idleFinish++`). 주기가 영원히 걸려 있는 일은 없다.
9. **견습생(자동)**: ≈3022행 틱의 `if(S.auto) spin();` 을 **견습생 박자**로 바꾼다 — `S.auto` 면 **500ms 마다 `strike('apprentice')`**(120 BPM — R2 에서 배경음악 박자와 맞춘다).
   사람이 같이 치면 그만큼 빨라진다. `S.auto` 의 저장·버튼·뜻은 그대로.
10. **문양 칸 누르기**: 주기 밖이면 지금처럼 고정 토큰(`buildReels()` 의 처리 그대로). **주기 안이면 치기**다(가려진 칸을 누르는 손은 치려는 손이다).
    지금 처리기는 `spinning` 만 보므로 정착 뒤 ~ 마무리 전에 누르면 **고정이 걸린다** — 이 틈을 막는다.

- **CORE 와의 산술**: 한 장비 = `spin()` 1회 = 충전 1 (D2 그대로). 하루 총 제련 수와 `days.js` 는 안 바뀐다.
  달라지는 것은 «쌓인 충전을 견습생이 비우는 속도» 하나다 — 지금 자동은 틱마다 시도해 ≈0.5초에 하나, 견습생은 `REELS()`×0.5초에 하나(3릴 1.5초).
  충전 회복은 6초에 1(테크로 1.5초까지)이라 **평상시 병목은 여전히 충전이다.** 이 차이를 K3 에서 잰다.
