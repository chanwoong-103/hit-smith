### ① 실효 판정 하나 — `autoResOn()`

`S.autoRes` 를 직접 읽던 **네 자리 전부**를 `autoResOn()` 으로 바꿨다. 저장값은 건드리지 않는다.

| 자리 | 전 | 후 |
|---|---|---|
| `qClear`(대기열 가득 표시) | `qFull && !S.autoRes` | `qFull && !autoResOn()` |
| `#spin` 클릭 | `if(S.queue.length>=qmax() && !S.autoRes)` | `… && !autoResOn()` |
| `autoResolve()` 첫 줄 | `if(!S.autoRes) return;` | `if(!autoResOn()) return;` |
| 250ms 틱 | `if(S.autoRes) autoResolve();` | `if(autoResOn()) autoResolve();` |

```js
function autoResOn(){ return (S.star||0)>=1 && !!S.autoRes; }
```
