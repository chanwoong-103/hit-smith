## 1. 반려 원문과 기준의 출처

- 반려(2026-10-08): 「The overall quality of the game does not yet meet the expectations of our platform.」
  기술 항목(용량·SDK·사이트락·Gameplay Start)은 미리보기에서 전부 통과했다 → **품질 판정**이다.
- 공식 기준: CrazyGames 문서 **Quality guidelines**(docs.crazygames.com/requirements/quality).
- 참여 지표(⚠ **제3자 보고서 수치, 공식 아님**): D1 재방문 10~15%(플랫폼 평균 ≈6.7%), 1분 넘게 하는 비율 80%+, 플레이 시간 10분+.
  같은 보고서: 장르 상위는 하이퍼캐주얼·퍼즐, **순수 방치/클리커는 상위가 아니다** — 「퍼즐 + 방치 성장 메타」가 권장 조합.

## 2. 공식 기준 대 Hit Smith — 차이표

| 공식 기준(요지) | Hit Smith 현재 | 판정 |
|---|---|---|
| 새 플레이어는 **게임플레이 안에 녹은 짧은 온보딩**으로 바로 들어간다. 글보다 그림 | 튜토리얼 없음. 제련·대기열·정리·등급·세부등급이 첫 화면에 한꺼번에 | ✘ |
| 분명한 목표 · 배우기 쉽다 · 이해하기 쉽다 | 「다음에 무엇을 하면 되는가」가 화면에 없다. 목표는 숫자(웨이브·전투력)뿐 | ✘ |
| 반응이 빠르다(입력 → 반응) | 제련 버튼 → 릴 정지 → 결과. 반응은 있으나 **손맛(타격감)이 약하다** | △ |
| 화면 배치가 편하고 직관적, 기기에 맞는다 | 1920×1080 에서 UI 가 위 45%만 채운다(036). 화면 대부분이 패널·표 | ✘ |
| **소리가 게임에 어울린다 · 음악이 시각을 보완한다** | **소리 0** — 효과음도 음악도 없다 | ✘ |
| 지루하게 반복되는 일을 피한다 | 핵심 동작이 「버튼 누르고 결과 확인」의 반복. 자동이 대신 하지만 **보는 재미**가 약하다 | △ |
| 고해상도 그래픽, 해상도 일관, 결함 없음 | 24~32px 스프라이트를 정수 확대. 결함은 없으나 「고해상도」 인상은 아니다 | △ |
| 시각 스타일 일관 | 게임 안은 일관(픽셀). **표지(일러스트풍)와 게임 안의 격차가 크다** | △ |
| 이름·그림이 실제 게임을 정확히 반영(오해 금지) | 표지는 화려한 대장간 장면, 게임은 회색 패널 위주 → 기대 불일치 | ✘ |
| 장르가 분명하다 | 「제련 + 웨이브 전투 + 탑 + 테크 + 승천」 — 층이 많아 장르가 한눈에 안 읽힌다 | △ |

✘ 다섯 개가 **그래픽·소리·첫 30초**에 몰려 있다. 수치·밸런스 쪽 결함은 기준표에 없다 —
**문제는 「무엇을 계산하는가」가 아니라 「어떻게 보이고 들리고 시작하는가」다.**

## 4. 사용자 결정 — 이것이 정해져야 039~ 를 쓴다

**결정 ① 그림의 길**
- (가) **픽셀 언어 유지, 크게** — 스프라이트 48~64px, 무대가 화면의 절반 이상, 타격·폭발·화면 흔들림 연출 강화. 손그림 상한을 올린다. 표지와 톤을 맞추려면 표지를 게임 실화면 기반으로 다시 만든다.
- (나) **일러스트 도입** — 배경·용사·몹을 생성 일러스트(표지와 같은 톤)로 바꾸고 파일 안에 넣는다. 「외부 이미지 금지」·손그림 상한을 푼다. 그림이 가장 크게 바뀌지만 등급 15종 팔레트 스왑이 깨지므로 장비 아이콘 체계를 새로 정해야 한다.

**결정 ② 소리** — WebAudio 로 **코드에서 합성**한 효과음(타격·등급 상승·처치·웨이브)은 에셋 0, 원칙 그대로 가능하다. 음악까지 넣을지.

**결정 ③ 화면의 주인공** — 「무대(전투·대장간 장면)가 화면의 주인공이고 패널은 보조」로 뒤집을지. 그렇다면 등급표·옵션 상세 같은 표는 접어 두는 자리로 밀려난다.

**사용자 결정 (2026-10-08): ① (가) 픽셀 유지·크게 · ② 효과음 먼저 · ③ 뒤집는다** — 계획 세션 추천과 같다.
계획 세션 추천 근거: 근거 — (가)는 지금까지의 검증 체계(SG·OC·ST 검사)를
대부분 살리고, 게임과 표지의 격차는 표지를 게임 쪽으로 맞춰서 없앤다. (나)는 사실상 새 게임이고, 그럴 바엔 C(새 게임)에서 처음부터 하는 편이 싸다.
