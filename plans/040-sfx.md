# 040 — 효과음 (WebAudio 합성) · 무거운 변경(새 메커니즘 · 새 검사) · 담당: 코딩 → 검증

상태: **대기 — 037 검증 통과 뒤 착수** (사용자 판정 2026-10-08: 037 먼저).
빌드 기준: 037 검증 통과 커밋. 근거: 038 결정 ② 「효과음 먼저」.
⚠ 037 이 들어온 뒤이므로 §④ 의 자동 정지는 **GD 광고(`SDK_GAME_PAUSE`) 에서도** S3 로 확인한다 — `?gd=1` 가짜 SDK 하네스 재사용.

## 왜

CrazyGames 반려(028)의 공식 기준 차이표(038 §2)에서 **소리 0** 이 ✘ 다섯 중 하나다.
「Audio should be comfortable and suited to the game」 「Keep audio levels consistent」.
지금 게임에는 `AudioContext`·`<audio>` 가 하나도 없다(035 영상 작업 확인).

## 원칙

- **음원 파일 0개.** 전부 WebAudio 로 코드에서 합성한다(원칙 2 · 외부 에셋 금지 유지).
- **CORE 를 한 줄도 안 건드린다.** 소리는 VIEW 의 **관찰자**다 — 상태(`S`)·변수(`spinning`)·`VIEW.counters` 의
  **변화를 보고** 소리를 낸다. 게임 함수 안에 소리 호출을 심지 않는다.
  (이유: CLAUDE.md 「사람이 가끔 누르던 함수를 기계가 매 틱 부르면…」 — 소리를 CORE 에 심으면 `days.js`·하네스가 그 길을 탄다.)

## 변경할 것

### ① 소리 모듈 `SFX` (VIEW 구획)

- `AudioContext` 는 **첫 사용자 입력(pointerdown/keydown)에서 만든다**(브라우저 자동재생 정책). 그 전에는 만들지 않는다.
- 출력 사슬: 소리별 노드 → `master`(GainNode, 기본 0.5) → `DynamicsCompressor` → destination. 동시 발음 **최대 8**, 넘으면 버린다(`dropped++`).
- `node` 하네스에서 eval 될 때 `AudioContext` 가 없으므로 전부 `typeof` 로 가린다(026 PLAT 주석과 같은 이유).

### ② 소리 7종 — 합성 레시피 (값은 시작점, 귀로 듣고 ±30% 안에서 조정 가능. 조정하면 「구현 결과」에 최종값)

| 이름 | 언제 (관찰하는 변화) | 레시피 |
|---|---|---|
| `spin` | `S.charge` 가 줄었다(제련 시작) | 노이즈 40ms 하이패스 3kHz + 사인 880→1320Hz 80ms, 0.15 |
| `land` | `spinning` 이 true→false (릴 정지). 맞은 릴 수 = 그 순간 `.reel.hit` 개수 | 0연: 사각파 330Hz 60ms 0.10 · 2연: 두 음(330·440) · 3연 이상: 세 음 아르페지오(330·440·660). **새 장비 등급 ≥10 이면** 사인 1760Hz 종소리(감쇠 400ms) 추가 |
| `hit` | 용사 공격이 **맞는 순간** 1회 증가하는 `VIEW.counters` 항목 | 삼각파 110→55Hz 90ms + 노이즈 30ms 로우패스 800Hz, 0.25. **간격 120ms 미만이면 생략** |
| `kill` | `VIEW.counters.dissolve` 증가 | 노이즈 120ms 밴드패스 1200→300Hz, 0.20 |
| `wave` | `S.wave` 증가 | 사각파 523→784Hz 두 음 각 70ms, 0.15 |
| `fail` | `S.wave` 감소(패배 후퇴) | 사각파 392→262Hz 두 음, 0.12 |
| `ascend` | `S.star` 증가 | 다섯 음 상승 아르페지오(262·330·392·523·659), 0.18 |

- `hit` 의 카운터는 **reducedMotion 에서도 한 번씩 증가하는 것**을 고른다(`hitstop` 은 reducedMotion 에서 안 오른다 — 3103행). 고른 이름과 이유를 「구현 결과」에 적는다.
- 자동 제련 중에도 귀가 피곤하지 않아야 한다: `spin`·`land` 는 **같은 소리 250ms 안 재발음 생략.**
- 소리 크기 일관(CrazyGames 기준): 7종의 최고 음량이 서로 ±3dB 안. 측정 방법은 §④.

### ③ 음소거 버튼 `#snd`

- 자리: `#hud .panel` 의 첫 `.row` 안, 골드·토큰 묶음(`#gold`·`#tok` 이 든 `div`) **오른쪽 끝**. 아이콘 버튼(스피커 / 스피커+가로선), 글자 없음, `title`·`aria-label` 은 `t()`(ko 「소리」/ en 「Sound」 — `STR` 키 1개 추가만 허용).
- 크기: 누를 수 있는 높이(LG 검사 기준 그대로). 이 줄이 넘쳐 줄바꿈되면 **멈추고 보고.**
- 상태는 `localStorage` 별도 키 `hs.snd`('1' 켬 / '0' 끔) — **세이브(`S`)에 넣지 않는다**(저장 형식 불변). 기본 켬. 키를 못 읽으면 켬.
- 켜짐 표시는 기존 `.hot` 방식이 아니라 아이콘 모양만 바꾼다(켜짐이 기본이라 늘 주황이면 시끄럽다).

### ④ 자동으로 꺼지는 때

- `PLAT.paused` 가 참인 동안(광고) — **소리 0**. `ctx.suspend()`. 끝나면 `resume()`.
- `document.hidden` 동안 — `suspend()`.
- CrazyGames SDK 의 오디오 음소거 설정이 있으면 따른다 — **SDK 문서에서 이름을 확인해서** 쓴다(추측 금지). 못 찾으면 「구현 결과」에 적고 생략.
- (037 이 뒤에 들어오면 GD 광고 정지도 `PLAT.paused` 를 거치므로 같은 규칙으로 꺼진다.)

### ⑤ 검증 창구 `__view.sfx`

`{on:bool, ctx:'none'|'running'|'suspended', played:{spin,land,hit,kill,wave,fail,ascend}, skipped, dropped}`
— `played` 는 **실제로 노드를 만들어 재생 예약한 수**, `skipped` 는 음소거·정지·재발음 생략으로 안 낸 수.

### ⑥ 037 에서 넘어온 둘 (계획 세션 2026-10-10 — 037 제안 ③·④, 검증 동의)

- **프리롤은 한 페이지 로드에 한 번** — `#gdStart` 를 다시 띄우는 경로가 없음을 코드로 못박고(플래그 하나), 검사로 확인한다.
- **PAUSE 이벤트 보루** — 미드롤·프리롤 요청 뒤 `SDK_GAME_PAUSE` 도 `SDK_GAME_START` 도 오지 않으면 일정 시간(구현 결과에 값과 근거) 뒤
  `PLAT.paused=false`·막 걷기로 게임을 돌려준다. 보상형의 90초 보루와 같은 생각. 이 보루가 소리 재개(§④)도 함께 되돌리는지 S3 와 같이 본다.
