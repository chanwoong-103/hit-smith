## 4. 새 핵심 루프 (안) — 「세 번 두드리면 하나가 나온다」

지금의 「릴 셋」은 그대로 **망치질 세 번**이 된다. CORE 의 `spin()` 이 고르는 부위 셋(`res[]`)을 **한 번 칠 때마다 하나씩** 보여 준다.

```
모루 탭 ─▶ 망치가 내려친다 ─▶ 불꽃 속에 부위 문양 하나 (res[0])
모루 탭 ─▶                   ─▶ 두 번째 문양 (res[1]) — 같으면 불꽃이 커진다
모루 탭 ─▶                   ─▶ 세 번째 문양 (res[2]) — 장비가 달궈져 튀어나온다 · 등급색 빛기둥
```

- **열기 = 지금의 충전.** 한 장비(세 번 치기)마다 열기 1 을 쓴다(지금 「제련 1회 = 충전 1」과 같다) → **하루 총 제련 수와 `days.js` 가 그대로다.**
- **Forge Rush(박자)**: 박자 창 안에 친 타격이 이어지면 콤보 — 콤보 중에는 **한 번에 두 문양**이 드러나 장비가 빨리 나온다.
  **양은 늘지 않고(열기가 상한) 속도만 빨라진다** → 접속 시간과 도달 일수가 무관하다는 검증 기준을 지킨다.
- **자동 = 견습생**: 견습생이 느린 박자로 대신 친다(지금의 「자동」). 사람이 치면 더 빠르고, 박자를 맞추면 더 빠르다.
- **릴 고정 토큰 → 「첫 타 조준」**: 토큰을 쓰면 첫 문양을 원하는 부위로 고른다(지금의 고정과 같은 결정 ①).
- **승천으로 릴이 늘면 → 치는 횟수가 는다**(3 → 4 → 5). 「숙련될수록 더 두드리고, 더 높은 정렬을 노린다.」
- **결과**: 장비 카드가 모루 위로 튀어나와 장비 칸 쪽으로 날아간다. 더 좋으면 바로 비교, 아니면 대기열로(자동 정리 규칙은 041 그대로).

⚠ 045 결정 ③ 은 「열기 상한형 망치질 뽑기 — 열기 10 = 뽑기 1회, **충전과 별개**」였다. 이 안은 **열기를 충전과 하나로 합친다** —
별도 열기 줄기는 하루 뽑기 수를 늘리는데, 026 실측대로 뽑기 수는 병목이 아니라 보상감이 약하고, 게이지 두 개는 첫 화면을 다시 복잡하게 만든다. → **결정 D2.**

## 7-c. 영원의 불씨 · 환생 스킬트리 (사용자 요구 2026-10-16) — 초안, 결정 대기

> 「환생의 재화는 영원의 불씨 같은 재화 명칭으로 가져가고, 별도 스킬트리로 다음 환생 후 시작이 강해질 수 있도록 해금하는 형태.」

**무엇이 바뀌나** — 지금 승천은 「별 +1 → 릴 +1 · 시작 상한 ↑」 자동 효과뿐이고, 고를 것이 없다. 여기에 **환생 전용 재화와 그걸 쓰는 나무**를 더한다.

- **영원의 불씨**(en *Eternal Embers*): 승천할 때 얻는다. 양은 **025 2단계 식을 그대로 옮긴다** —
  `불씨 = round(peak × (1 − e^(−Δt/4h)))`(관문이 열린 뒤 오래 버틸수록 더 받는다). 025 2단계가 별가루에 주려던 것을 불씨로 돌린다.
- **영원의 화로**(환생 스킬트리 화면): 승천 직후 열리고, 이후엔 탭에서 언제든. 배경음악 **Embers at Midnight**.
  첫 승천 전에는 **보이지 않는다**(첫 3분·첫 주기에 결정을 더하지 않는다 — 원칙 4·7).
- **노드 초안 — 세 갈래 · 12개 · 전부 「다음 판의 시작」을 바꾼다**:

| 갈래 | 노드 (단계) |
|---|---|
| 🔥 **화로**(열기) | 시작 열기 가득 · 열기 상한 + · 열기 회복 + · 자리 비움(오프라인) 효율 + |
| 🔨 **망치**(제련) | 시작 제련 레벨 +1 (최대 5) · 고정 토큰 시작 + · 임계압 시작치 + · 시작 등급 바닥 +1 |
| 🧑‍🔧 **견습생**(자동) | **자동 정리**(첫 노드) · 대기열 +1 · 견습생 박자 + · 시작 웨이브 = 직전 최고의 10% |

- 별(승천 횟수)의 자동 효과(릴 수 = 두드리는 횟수, 시작 상한)는 **그대로 둔다** — 이정표는 자동, 선택은 나무.
- **CORE 변경이다**(새 재화·새 상태·`ascend()`·시작 적용 함수·저장 필드). `days.js` 출력이 바뀌므로 **새 기준 md5 를 지시서에 박는다.**
  페이싱 기준 「첫 승천 5일 전후」는 그대로 두고, 「이후 승천 2~3일 주기」는 **회차마다 줄어드는 곡선**으로 다시 정한다(아래 E4).

**결정 — 나무 지시서(R3) 전에 정한다**:

- **E2 자동 정리(041)** — (가) **나무의 첫 노드로 옮긴다**: 첫 승천 직후 **사용자가 직접 찍는 첫 선택**이 된다(추천 — 해금 보상의 손맛이 커진다) / (나) 041 그대로 첫 승천 때 저절로

## 7-d. 「정렬」을 다시 정의한다 — 양 끝 고정 · 가운데만 돈다 (사용자 2026-10-18) → R3

> 「그때 있던 정렬 기능을 바꿔야겠어. 맨 왼쪽 릴에 맨 오른쪽 장비 정렬이 고정된 채로 뜨는 임팩트에서, 가운데만 또 따로 돌리는 형태.
> 그래서 더 큰 등급의 최소가 보장되는 거지(2개가 같으니). 3연 기능은 또 다른 명칭의 기능으로 가고.」
> 확률: 「**기본 확률 + 영원의 화로로 올림**」(계획 세션 추천안).

**지금(계획 세션 확인, CORE `spin()`)**: 테크 「정렬 보정」(`T('align')`, 단계당 0.25% · 최대 25%)이 터지면 **아무 릴 하나를 다른 아무 릴에 몰래 맞춘다**(`res[a]=res[b]`).
화면에는 아무 표시가 없어 플레이어는 그것이 터졌는지 모른다. 그리고 「정렬」이라는 말은 지금 **모든 일치**에 쓰인다(「3연 정렬」·「임계압 정렬」·「2연」).

**새 규칙**
- **정렬** = 터지면 **맨 왼쪽 릴과 맨 오른쪽 릴이 같은 장비로 고정된 채 «쾅» 하고 한꺼번에 선다.** 가운데 릴(3릴이면 1개, 4릴이면 2개, 5릴이면 3개)만 계속 돌고, 플레이어가 마저 세운다.
  → **2연 이상이 보장**된다(등급 보정 `b ≥ 1`). 가운데가 같은 문양으로 서면 그대로 3연 이상.
  - 고정 토큰이 **바깥 릴**에 걸려 있으면 반대쪽 바깥이 그 장비를 따른다(토큰과 정렬이 서로 돕는다). 가운데에 걸려 있으면 바깥 짝은 따로 정해진다.
  - 천장(압력계 가득 → 전 릴 일치)이 정렬보다 먼저다.
  - 탭 수: 정렬 판은 첫 탭에 바깥 둘이 같이 서므로 **릴 수 − 1** 번이다.
- **확률** = 기본값(첫 회차부터 가끔 — 손맛) + **영원의 화로 노드**로 오른다. 별가루 테크의 「정렬 보정」 갈래는 **화로로 옮긴다**(테크 6갈래 → 5갈래, E3 의 「둘 다 둔다」는 그대로 — 갈래 하나가 자리를 옮길 뿐).
  수치는 R3 에서 `days.js` 로 정한다(시작점: 기본 5% · 화로 최대 +20%p — 지금 테크 상한 25% 와 같은 천장).
  아직 출시한 빌드가 없어 옛 세이브의 테크 `align` 단계는 **불씨로 환불**하는 불러오기 보정 한 줄이면 된다.
- **이름 — 사용자 확정 (2026-10-18)** · 영어는 계획 세션 안:

  | 무엇 | 한국어 | 영어 |
  |---|---|---|
  | 모든 릴이 저절로 일치(자연 3연 이상) | **완벽한 제작** | *Masterwork* |
  | 압력계 천장 — 전 릴 강제 일치(지금 「임계압 정렬」) | **특별 주문 제작** | *Special Commission* |
  | 새 정렬 사건 — 양 끝 고정 · 가운데만 돈다 | **대장장이의 감!** | *Smith's Instinct!* |
  | 2연 | 「2연」 그대로 | *2 matched* |

  「정렬」이라는 낱말은 화면 문구에서 빠진다(기능 설명·코드 이름 `align` 은 그대로 둬도 된다). 압력계 안내 `ui.pityFull` 「다음 제련은 전 릴 정렬」도 「다음 제작은 특별 주문」 꼴로 바뀐다.
  글자 교체는 R3 지시서에서 **새 키**로 한다(기존 키 값을 바꾸면 CORE `STR` 값 변경이 된다 — R3 은 어차피 CORE 변경 단계다).

**어디서 하나** — **R3(영원의 불씨·화로)와 한 지시서.** 이유: 기본 확률이 생기는 순간 첫 회차의 등급 분포가 바뀌어 `days.js` 기준이 새로 서야 하고(R3 가 어차피 새 기준을 세운다),
