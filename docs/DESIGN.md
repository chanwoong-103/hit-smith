# DESIGN.md — 확정 설계 (2026-08 기준)

여기 적힌 것이 게임의 전부다. 없는 시스템은 미확정이며 계획 세션 승인 전에는
구현하지 않는다.

## 핵심 루프
스핀(제련) → 릴 정렬로 장비 획득 → 대기열에서 교체/판매 결정 → 장비가
웨이브를 민다 → 골드로 제련 강화 → 등급 상한 개방 → 승천 → 반복.

## 릴과 정렬
- 부위 6종: 무기·모자·상의·하의·장갑·신발. 릴 수 = 3 + 별 (최대 5).
- 같은 부위가 많이 정렬될수록 등급 보너스 b = (최대 일치 수 - 1).
- 꽝 없음: 정렬 실패여도 아이템 1개는 반드시 나온다.
- 고정 토큰(⬢): 스핀 전 릴 하나를 원하는 부위로 잠근다. 해제 시 환불.
  수급: 상한 기준 상위 3등급(g ≥ cap-2) 장비를 **수동 판매**할 때만 +1.
  자동 판매는 토큰을 주지 않는다 (희소성 유지).

## 천장 게이지
- 스핀마다 +1, 문턱 = 20 × 릴 수. 가득 차면 다음 스핀은 전 릴 강제 정렬.
- 자연 전릴 정렬이 떠도 게이지는 0으로.
- 고정 릴이 있으면 천장 정렬이 그 부위로 터진다 = 조준 메커니즘.
- **내부 명칭은 "천장", 화면 라벨은 제련 용어** (002에서 확정):
  진행 중 `화로압 n/N`, 가득 `▣ 임계압`, 강제 정렬 `▣ 임계압 정렬`.
  문서·코드에서는 천장이라 부르고, 화면에는 절대 노출하지 않는다 (원칙 7).

## 등급과 옵션
- 등급 1~15. 색상 변수 --g1~--g15. 세부등급 I~X (제련 강화가 분포를 밀어올림).
- 옵션 줄 수: 1~2등급 1줄 / 3~6등급 2줄 / 7~10등급 3줄 / 11~15등급 4줄.
- 옵션 10종, 축 3개: 화력(치확·치피·공속·더블어택·근접피해·원거리피해),
  생존(체력·블록·흡혈), 재화(골드 획득). 수치는 범위 내 랜덤 (이중확률).
- 곱연산 폭발은 옵션별 수치 상한(cap)으로만 제어한다. 부위별 풀 분리는 하지 않음.
- 무기: 근접/원거리 2타입. 타입과 안 맞는 피해 옵션은 죽은 옵션(취소선 표시).
- 각인: 9등급 이상 1개. 처형/광폭/재생/관통. 관통 = 안 맞는 피해 옵션 절반 적용.
- 블록은 근접 적에게만 유효. 웨이브 패배 = 체력 소진 → 전 웨이브로 후퇴
  (1웨이브가 하한, 절대 그 밑으로 안 밀림).

## 등급 상한 개방과 승천
- 시작 상한 5등급. 제련(골드 강화) 2단계마다 +1, 제련 20에서 15등급 전부 개방.
- 상한 개방 후 제련 강화는 등급 확률을 더 밀지 않고 **세부등급만** 밀어올린다.
- 승천 조건: 제련 28 **그리고** 이번 주기 최고 웨이브 ≥ 100 + 별×12.
  (관문 증가폭 12는 승천 이득 +12웨이브와 맞물린 값 — 절대 이보다 크게 잡지 말 것,
   별이 쌓이면 영구 정체된다. BALANCE.md 참고.)
- 승천 효과: 장비·대기열 전부 판매(골드 환급), 제련 0으로, 별 +1.
  기본 수치 ×4, 옵션 수치 상한 ×(1+0.6×별), 릴 +1(최대 5), 대기창 +1.
  등급 곡선은 매번 5등급부터 동일 (완전 초기화형).

## 대기열 (인벤토리 아님)
- 전 부위 공용, 기본 10칸 + 제련 7단계마다 +1 + 별당 +1. 가득 차면 스핀 정지.
- 맨 앞 장비 하나만 처리: [판매 ◈가격] / [교체해서 껴보기].
- 교체하면 빠진 장비가 맨 앞으로 → 껴보고 확인 후 되돌리기 가능.
  **판매만이 대기열을 줄인다** (미루기 불가 원칙).
- 팝업은 교체 후에도 유지(카드가 뒤바뀜). 닫기 버튼/배경 탭으로 닫고 화면 확인
  가능, 팝업 상단에 전투력·웨이브·골드 실시간 표시.
- 낮은 등급(2등급 이상 차이) 교체 경고는 장비당 1회만.
- 자동 판매: 등급별 개별 체크. 체크된 등급은 대기열을 거치지 않고 즉시 골드.

## 재화 (수입원 = 재화 수)
1. **스핀 충전** — 시간. 기본 6초/1, 상한 600 + 테크. 오프라인 = 델타 계산.
2. **골드(◈)** — 장비 판매 + 웨이브 클리어. 용도: 제련 강화(상한 개방).
3. **별가루(✦)** — 무한의 층 전용. 용도: 테크트리.

## 무한의 층
- **점진 노출**: 층 UI(티켓 표시 포함)와 테크트리는 최고 웨이브 10 도달 전까지
  숨김 (원칙 7 — 첫 접속은 순수 스핀만). 진행 기반, 타이머 기준 금지. 노출
  여부는 최고 웨이브에서 파생 — 별도 저장 없음. 티켓 적립·리셋 로직은 숨김
  중에도 동작.
- 티켓 하루 2장 (날짜 문자열 비교로 리셋, 서버 없음).
- 웨이브 전투 공식 재사용, 오를 수 있는 층까지 자동 등반, 층수가 보상 규모.
- 완주 후 주사위 판: 8칸 순환, 말 위치는 영속. 주사위 굴려 착지 칸이 보상
  (별가루 ×1/×2/×3.5, 골드, 고정 토큰, 충전 가득).
- 광고 재굴림 최대 2회. 골드 칸은 현재 강화 비용 비례 (층수 비례 금지 — 폭발).

## 테크트리
- 6갈래 × 100단계: 충전 속도 / 저장 한도 / 판매 금액 / 강화 비용(-50% 바닥) /
  골드 획득 / 정렬 보정. 비용 8×1.09^lv.
- 의도: 사실상 완주 불가능한 장기 싱크. "다 올리면 재화가 필요 없어진다"를 막는다.

## 광고 (전부 리워드형, SDK 자리만 비워둠)
1. 충전 가득 + 30분 1.5배속 (메인 버튼)
2. 무한의 층 주사위 재굴림 (최대 2회)
3. (예정) 티켓 하루 +1
- 배속형은 창을 열어둘 이유를 만들어 노출을 늘린다. 즉시완료형보다 우선.

## 표시 규약 (002에서 확정 — 디자인 세션이 먼저 읽을 것)

- **게이지는 진짜 상한이 있을 때만 만든다.** 충전(`CHG_MAX()`)·천장(20×릴 수)·
  체력처럼 분모가 실재하는 값만 눈금으로 그린다. 전투력·공격력처럼 상한이
  없는 값에 세로 게이지를 붙이면 눈금이 거짓말이 된다 — 숫자로만 표시한다.
  (레퍼런스 이미지에 그런 게이지가 있어도 따라가지 않는다.)
- **화면 용어는 대장간 제련 어휘로 통일.** 천장→화로압/임계압처럼, 내부
  명칭과 화면 라벨이 다를 수 있다. 새 라벨을 만들면 이 문서에 적어야
  검증 도구가 무엇을 검사할지 알 수 있다 (002의 `3b` 충돌 원인).
- 이모지 금지, 인라인 SVG만. 등급색 `--g1~--g15` 고정.
- 장비 아이콘 = 부위 실루엣 3단계 × 등급색 × 상위 이펙트(11+ 발광, 14~15 오라).
  부위×등급 개별 드로잉 금지.

## 수동 플레이 체크리스트 (검증 세션용)
- [ ] 첫 접속: 충전 **600**(테크 0 의 `CHG_MAX()` · 온도계 가득 — 032 전에는 30),
      튜토리얼 없이 스핀 즉시 가능, 데일리/타이머 안 보임,
      무한의 층·테크트리 미노출 (웨이브 10 도달 시 노출)
- [ ] 세이브 로드 상태(★3 이상 포함)에서도 콘솔 self-check 무오류
- [ ] 2연 정렬 시 니어미스 하이라이트, 3연+ 시 강조 메시지
- [ ] 천장 게이지 상승·가득 시 색 변화·강제 정렬·리셋
- [ ] 고정 → 해제 시 토큰 환불
- [ ] 교체 왕복: 팝업 유지, 델타 반전, 경고 1회, 판매로만 종결
- [ ] 대기 가득 → 스핀 정지 → 정리 후 재개
- [ ] 자동 판매 체크 등급은 대기열 미진입 + 토큰 미지급
- [ ] 승천 버튼: 조건 미달 시 숨김, 관문 진행 문구 표시
- [ ] 층 → 주사위 → 재굴림 2회 제한 → 보상
- [ ] 새로고침 후 상태 복원 (오프라인 충전 포함)
