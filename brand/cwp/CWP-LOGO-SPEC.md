**살릴 것: 이름(CWP · ClockWise Player)과 「시계 방향」이라는 발상.** 형태는 전부 버린다.

## 2. 컨셉 — 「3시를 가리키는 재생 버튼」

> **시계판 위의 재생 삼각형.** 삼각형이 곧 시침이고, 12시에서 시계 방향으로 한 칸 돈 **3시**를 가리킨다.

- **Clock** = 원판 + 12·6·9시 눈금 (3시 눈금은 없다 — 삼각형이 그 자리를 가리킨다)
- **Wise / 시계 방향** = 12 → 3 의 사분의 일 회전
- **Player** = 재생(▶). 사람 실루엣이 아니라 「게임을 튼다」
- **1인 개발 · 픽셀** = 16×16 픽셀 격자. 만든 게임과 같은 언어이고, **16·32·64px 에서 정수 배율로 정확히** 찍힌다

16px 로 줄면 눈금은 사라지고 「주황 원 안의 재생 삼각형」만 남는다 — **의도된 퇴화**다. 가장 작을 때 가장 단순한 의미(재생)만 남는다.

## 3. 사양 — 이것과 다르면 반려

### 3.1 격자 (원본 = 이 표, 한 칸 = 1 단위)

```
................      # = 표시색   . = 바탕(투명/배경)
....########....
...####..####...      ← 12시 눈금 (2×1, 열 7–8, 행 2)
..############..
.####..########.
.####....######.      삼각형: 열 5–11, 밑변 행 4–11(8칸), 꼭짓점 열 11 행 7–8
.####......####.
.#.##.......###.      ← 9시 눈금 (1×2, 열 2, 행 7–8)
.#.##.......###.
.####......####.
.####....######.
.####..########.
..############..
...####..####...      ← 6시 눈금 (2×1, 열 7–8, 행 13)
....########....
................
```

- 바깥 1칸은 비운다(원형 자르기 안전 여백). 원판은 행·열 1–14.
- **3시 눈금 없음.** 넣으면 삼각형 꼭짓점과 붙어 오른쪽이 터진다.
- 가장자리에 홈·돌기 금지 — 톱니바퀴(설정 아이콘)로 읽힌다. (계획 세션이 시험해 보고 버린 안이다.)

### 3.2 색 — 이 셋만

| 이름 | HEX | 쓰임 |
|---|---|---|
| Forge Orange | `#F08A24` | 기본 표시색 |
| Ink | `#1B1B22` | 기본 바탕 / 단색판 표시색 |
| White | `#FFFFFF` | 밝은 바탕 / 어두운 바탕 단색판 |

그라데이션 · 그림자 · 외곽선 · 질감 · 광택 · 3D **전부 금지.** 한 그림에 색은 **정확히 2개**(표시색 + 바탕, 또는 표시색 + 투명).

### 3.3 판본 4개

| 파일 | 표시 / 바탕 | 용도 |
|---|---|---|
| `cwp-mark-512-dark.png` | 주황 / Ink | **기본.** 개발자 아바타, SNS 프로필 |
| `cwp-mark-512-mono-ink.png` | Ink / 흰색 | 밝은 배경, 문서, 인쇄 |
| `cwp-mark-512-mono-white.png` | 흰색 / Ink | 어두운 배경 단색 |
| `cwp-mark-512-transparent.png` | 주황 / 투명 | 게임 크레딧, 다른 그림 위 |
| `cwp-lockup.png` · `cwp-lockup-light.png` | 기호 + 글자 (어둡게 / 밝게) | 게임 크레딧 화면, 소개 페이지, 포털 개발자 소개 |

### 3.4 내보내기

- **정수 배율만**: 16 · 32 · 64 · 128 · 256 · 512px. 최근접(nearest) 확대. 1.5배 같은 비정수 금지 — 칸 크기가 들쭉날쭉해진다.
- SVG 는 `shape-rendering="crispEdges"`, `viewBox="0 0 16 16"`.
- PNG 에 안티앨리어싱 0 — 색 수를 세면 2 여야 한다.

### 3.5 글자 조합 (lockup)

- **아바타·파비콘 = 기호만.** 기호 안에 글자를 넣지 않는다.
- 가로 조합: 기호 | 간격 3단위 | `CWP` (굵은 산세리프 — Pretendard Bold 또는 Inter Bold) / 그 아래 `ClockWise Player` (같은 서체 Regular, CWP 의 약 40% 크기, 어두운 바탕에서 `#A8A8B3`).
- `CWP` 대문자 높이 ≈ 기호 높이의 45%. 기호와 글자 블록은 세로 가운데 정렬.
- 표기는 **ClockWise Player** 로 고정(W 대문자 = 약자 CWP 의 근거). Clockwise / CLOCKWISE 혼용 금지.
- 글자에 픽셀 서체 금지 — 기호와 글자가 둘 다 픽셀이면 서로 싸운다. 픽셀은 기호 하나만.

### 3.6 여백 · 최소 크기

- 사방 여백 ≥ 2단위(기호 높이의 1/8).
- 최소 16px. 16px 미만으로 쓰지 않는다.

## 5. 시안을 만드는 법

**가장 빠른 길: 기준안 A(이 폴더의 SVG·PNG)를 그대로 쓴다.** 이미 L1~L8 을 통과한다.
생성기(Gemini 등)는 픽셀 격자를 정확히 못 그린다 — 쓰려면 **색·분위기 탐색용**으로만 쓰고,
최종 파일은 §3.1 표에서 다시 찍는다. 생성기 그림을 최종본으로 받으면 L1·L2·L7 에서 거의 확실히 떨어진다.

다른 컨셉을 시도하고 싶다면 그것도 받는다. 다만 **§1 의 8개 결함을 하나도 되풀이하지 않고**
§3.2 색 · §3.4 내보내기 · §4 L2~L5·L7·L8 은 그대로 적용한다.
